# Unit HP Bars

Hides the stock health/progress overlays, commander name tags, rank icons, and ETA overlays, and displays one clean numeric text stack for visible units/features: Player name (in team color), HP, real-time movement speed, per-second Metal/Energy production and consumption, Shield current/capacity (always shown), Capture, Stockpile, EMP, Reload, Building, ETA/Decaying, remaining build Metal/Energy, Paralyzed, Feature Health, reclaimable Metal/Energy, Reclaim and Resurrect. Resource flow uses `+production/-consumption`. HP uses `HP current/max` and transitions from green through yellow to red. When adjacent units of the same type have the same actual current/max HP, current speed, or Metal/Energy flow, only the lowest-ID unit keeps that shared line; differing values remain visible. The stock overlays stay disabled until manually enabled again.
